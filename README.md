# 🟢 Storify

**Smart Ecommerce Management Made Simple**

Storify is a modern and futuristic ecommerce platform designed to deliver a clean, intelligent, and premium shopping experience for both customers and administrators. Built with a sleek dark interface inspired by high-end digital products, Storify combines product management, order tracking, analytics, and customer-focused shopping in one unified system.

---

## ✨ Overview

Storify is more than just an online store. It is a complete ecommerce management platform built to make online purchasing smarter, faster, and more organized.

With dedicated **Admin** and **Customer** views, Storify allows businesses to manage products, monitor orders, track analytics, and provide a modern shopping journey across desktop and mobile devices.

---

## 🚀 Key Features

### 🛍 Smart Product Browsing
Customers can explore products through a clean and responsive interface with modern product cards, search functionality, product details, and smooth mobile shopping behavior.

### 🧾 Order Management
Storify supports a complete order lifecycle, from cart and checkout to tracking, delivery updates, and order receipt confirmation with rating and feedback.

### 📦 Admin Product Control
Administrators can manage products efficiently by creating, editing, updating, and deleting product listings while maintaining stock visibility and product image consistency.

### 📊 Analytics Dashboard
The admin dashboard provides useful insights into store performance, product movement, order activity, and operational summaries.

### 👤 Personalized User Profiles
Users can register with name and profile image, update their account details, and manage their profile settings. Google login is also supported with default avatar handling.

### 📱 Mobile-First Experience
Storify is optimized for responsive behavior and modern app-like interactions, especially for mobile users, with improved product browsing and customer navigation.
